# Union 网关 0.1.0 应用验证记录

日期：2026-10-25。交付范围：可部署的 Linux amd64 Docker 网关及离线部署包。真实 Union 成员登记和游戏客户端验收由远端环境完成，本记录不将其标为通过。

## 已实现

- Element Skin Yggdrasil 登录、刷新、校验、失效、登出和进服代理。
- 本地角色权威回查、中心 mapped 身份一致性检查、网关 join 关联和 hasJoined 出口重签。
- Union metadata、公钥发现、允许材质域名和 unsigned 查询语义。
- SQLite 状态、独立私钥代次、凭证轮换、原子 nonce 防重放和重启恢复。
- 目录更新、全量 UUID→角色名对账、服务应用 token、可选 Webhook 的持久化去重及退避重试。
- 受保护管理 API、CLI、健康检查、请求 ID 和脱敏日志。
- 非 root、只读根文件系统的 scratch 镜像，Docker Compose、HTTPS 示例及离线打包程序。

Windows 本机 race 运行器在旧 MinGW 环境下以 0xc0000139 退出；已改在 Linux 容器实际完成 race 验证。Docker Hub 基础镜像拉取遇到本机网络限制；实际交付镜像使用静态 Linux 二进制与已校验 Mozilla CA 包，从 scratch 构建并验证，不依赖本机基础镜像拉取成功。

容器内对公开 Union 控制根的 HTTPS GET 未在本机 3 秒探测中完成，返回 upstream_unavailable；该探测未携带成员凭证。容器到中心的真实出口连通性与协议验收仍需在远端检查，不包含在“容器启动通过”的结论中。

## 失败状态覆盖

- 无效账号、token、角色、会话与权限拒绝不会生成网关成功身份。
- 未经网关 join、主站拒绝、未知或错误 profile、畸形材质及不允许的材质域名不会获得签名。撤销 token 后先被 validate 拒绝，不再调用可能 fallback 的 hasJoined；重启不会恢复内存 token。
- 重复和无效回调不修改业务状态；并发同 nonce 只占用一次。
- 同版本不同密钥、回退、无效 PEM、公钥不匹配不会修改 active 代次。
- 数据库触发的写入失败会回滚目录、密钥指针、角色索引、Webhook receipt 和 join 关联的对应事务。
- 分页失败不提交部分全量；重复或乱序事件通过重新枚举当前权威状态收敛。
- 持久化私钥缺失会明确拒绝启动，不自动生成自有密钥冒充 Union。
- 未实现 remap 明确返回 501 并阻止受影响角色，不静默修改主站 UUID。

## 交付文件

dist/ 下生成 docker.zip、镜像 image.tar.gz 和 zip 的 SHA256 文件。部署包包含 Compose、配置模板、HTTPS 示例、部署文档及容器 smoke 脚本；不包含真实凭证、生产配置、数据库或私钥。

运行镜像和部署文档共享同一版本 0.1.0。打包时检查镜像 version 命令与包版本相同；解压后可直接 docker load，再按文档配置运行。

## 仍需远端验证

- 非 Blessing 网关版本、功能声明及首次登记流程是否被真实中心接受。
- 中心实际 hasJoined 路径、参数、时延、身份映射与 IP 语义。
- 无冲突测试角色的真实联合进服、皮肤及披风显示、无权限拒绝。
- 中心共享密钥轮换、客户端缓存过渡、queryemail 与黑名单的准入要求。

未向真实 Union 中心提交角色、变更成员状态、拉取共享私钥或使用生产用户 token。本地通过结果只支持部署包和受控协议行为，不替代上述远端结论。
